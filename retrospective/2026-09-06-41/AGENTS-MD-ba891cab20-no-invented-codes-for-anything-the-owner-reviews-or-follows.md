# agent instruction

**No invented codes for anything the owner reviews or follows.** Write events, levels, phases, and categories out by name everywhere they appear: in tables, in front matter, and in prose. Do not coin short codes such as E1, G, or M2 for things a human must review, compare, or act on, even when a code would make a table narrower. If an ordering matters, let the table order or a descriptive name carry it.

*Grounded in: the event-code and maturity-code rewrite across twenty files in PR #41.*

# justification

In PR #41 the interface between the ideas directory and agent-method was first written with event codes (E1 through E7, G, M) and the maturity ladder with level codes (M0 through M5). The owner's response was that abbreviations like that are very confusing and that codes should not be made up for things he needs to review or follow. Undoing it took a full pass over the README, the plan, the decisions log, fourteen nugget front matters, and five spine documents, plus a PR description rewrite. The codes had saved a few characters per table cell and nothing else. Writing names costs a wider column. The asymmetry is a twenty-file rewrite against a wider column, and the rule is one sentence to remember.
