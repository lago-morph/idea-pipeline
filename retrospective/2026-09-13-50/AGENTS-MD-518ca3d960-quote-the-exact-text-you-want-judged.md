# agent instruction

**Quote the exact text you want judged.** "When asking a subagent to evaluate existing content, paste the exact lines verbatim into the brief and ask for a verdict on each — stands, needs narrowing with replacement wording, or unsupported. Naming the file instead gets you a review of the file."

*Grounded in: four evidence lines rewritten from per-line verdicts returned against quoted text.*

# justification

Briefs in this session quoted the specific evidence lines under scrutiny and asked for one of three verdicts on each, with replacement wording required for any narrowing. Readers returned line-by-line judgements that were directly applicable: one line's claim was narrowed from universal to eleven of thirteen, another had a qualifier removed because it no longer applied, and a third was rewritten to carry the statistical weakness of its underlying experiment. A brief that says "review this page" returns prose about the page, which then has to be translated into edits by the orchestrator — who is the party least able to check it. The marginal cost is pasting a few lines; the return is edits that can be applied verbatim.
