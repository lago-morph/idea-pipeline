# agent instruction

**Two evidence lines from one source is not corroboration.** "When a promotion or confidence threshold counts evidence, count independent sources, not lines. A second line drawn from the same source is more detail on one finding; never write one to clear a threshold, and never promote on one."

*Grounded in: two pages in this session deliberately given a single evidence line to avoid tripping a "≥ 2 evidence lines" promotion rule.*

# justification

The threshold in this corpus was written as "promote candidates with ≥ 2 evidence lines". Twice in one session a page was deliberately given one evidence line, despite its source supporting two distinct observations, purely to avoid an automatic promotion on a single finding. Meanwhile three existing candidate pages were found carrying two and three lines each from a single source, correctly unpromoted — an earlier session had silently applied a stricter rule than the one written down. A rule that every reader quietly reinterprets is not doing any work, and the reinterpretations diverged in both directions. The marginal cost of the fix is one word in the rule text. The cost of leaving it is that the injectable artifact an agent loads gets populated by whoever split one finding into two sentences.
