# agent instruction

**Name it before you cite it.** Before writing a cross-reference in any document, confirm the target has a stable citable identity — a numbered section, a labeled criterion, a named table. If the target is an unnumbered structure (an intro, a header table), refer to it in words ("the header table at the top of this document"); never invent shorthand like "§0" for something that has no number.

*Grounded in: two "§0" references to process.md's unnumbered intro, caught only in the re-read pass.*

# justification

While drafting process.md's appendix, the intro's four-question table needed citing twice; because the intro had no section number, "§0" got invented on the spot — twice, in two different passes — and both references shipped into the draft. They were caught only by the re-read pass's section-reference grep; had they survived, the pressure-test executor (whose defect records cite section labels) would have hit a dangling reference at the exact moment the protocol tells them to be precise. The rule costs one second of thought per cross-reference; a phantom reference costs a reader a search of the whole document for a section that does not exist.
